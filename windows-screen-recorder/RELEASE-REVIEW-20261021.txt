DONE — STABLE PACKAGE
- Supported cross-app desktop-session capture, durable save and semantic replay.

  verification; fixed-text paste records the destination value.
- Minimize capture and restoration before playback focus.

  manual observation and leave the run stopped; they never automatically replay.

  instead of silently disappearing as ordinary editor Tab.
- Versioned, manifest-verified Windows package with retained rollback release.

EVIDENCE
Before this release: real UI automation record/save/restart/replay passed the
nine-action Edge/Notepad copy-minimize-paste-return workflow, with independently
read final text. Real Streamlit dropdown selection replay also passed. Those
trials used explicit injected-input TEST mode, not human physical-input proof.
Normal installed operation excludes injected test input.
Release source: 52 recorder tests plus 85 helper/integration tests and 14 subtests
passed. Native package compiled. Render topology validator passed. A first
unittest invocation used the wrong harness/path for the pytest suite; rerunning
with pytest and the intended source path passed all helper tests.
The final stable change to Ctrl+Tab is a stop guard; the tab replay candidate is
not part of the installed executable. Final installed UI acceptance remains a
separate check from package/import/health checks.
