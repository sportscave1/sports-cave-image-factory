# Sports Cave OS application-wide UI/UX V1

10 October 2026 (Australia/Sydney). **Implemented locally in 34 routes; overall project remains pending.** No commit, push, merge, deployment, production migration, email send, product publication or operational production mutation.

## Scope and authoritative inventory

All **48 registered routes** were opened through the actual dispatcher in an isolated loopback fixture. The source inventory records **520 native presentation call sites**, their owning functions, dispatcher branches and custom component entry files. No source parsing failures. Design Schedule and Design Tracking are secondary workspaces, not extra registered routes.

Opening an offline or unconfigured screen is not populated-workflow acceptance. The 19 requested criteria are tracked per route in [page assessments](appwide-ui-v1-evidence/page-assessments.json). Dynamic dialogs and component-internal surfaces remain explicitly pending.

Existing unrelated dirty changes were preserved. - Chrome and Edge are not available through the connected browser surfaces. Their acceptance remains pending. Populated QA/certificate dialogs, Escape handling, full screen-reader audit and conditional saved/unsaved states remain pending.

## Performance comparison

The first AppTest fixture reparsed large source files per rerun. That test-only overhead made comparisons misleading; [raw uncached results](appwide-ui-v1-evidence/uncached-fixture-timings.json) are retained for transparency. Compiled public source extraction is now cached only in the fixture, with identical workload and warmup in both phases. No customer/provider response is cached by this change.

20 warm AppTest reruns per route and phase. Figures below are **render-only synthetic fixture timings**, excluding source extraction, shared-shell injection, browser and live DB/API latency. They show a small styling cost, not a production speed improvement.

| Route | Before render p50/p95 (ms) | After render p50/p95 (ms) |
|---|---:|---:|
| Prodigi | 4.86 / 5.94 | 5.03 / 6.68 |
| Webhook Events | 1.89 / 2.25 | 2.32 / 2.55 |
| Sync Runs | 1.98 / 2.36 | 2.38 / 2.69 |
| App Errors | 2.03 / 2.33 | 2.21 / 2.71 |
| Persistence Check | 3.18 / 3.68 | 3.53 / 4.22 |

[Full warm-rerun samples and driver timings](appwide-ui-v1-evidence/local-rerun-timings.json). Fulfilment browser readiness, five samples per phase: p50 1422→1410ms and p95 1532→1453ms; these include automation transport and uncached fixture extraction, and do not establish a meaningful real-world improvement. [Browser samples](appwide-ui-v1-evidence/fulfilment-browser-readiness.json). No new reads, polling or background initialization were added. Real button feedback, production navigation p50/p95, cold loading, CPU/memory, data-call counts and populated performance for the other routes are pending.
