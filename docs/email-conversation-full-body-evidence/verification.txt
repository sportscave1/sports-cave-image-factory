Root causes
The server exposed only explicitly expanded bodies. The browser additionally collapsed cached older messages, hid plain-text quotes, and offered per-message and conversation expand/collapse controls.
The received HTML sanitizer allowed zero/tiny line heights, negative margins and fixed text-container heights. A synthetic reproduction produced 44 overlapping glyph lines. The iframe measured body.scrollHeight, which cannot reliably account for content painted outside a fixed-height text block, and could retain a viewport-size floor on shrink.
There was no production message available in this task: the historical individual email cannot be conclusively identified. The underlying permitted layout failure is reproduced and fixed with synthetic input.

Implementation
All cached conversation bodies and plain quoted replies render automatically. Missing bodies hydrate serially only for the selected conversation, through the existing async body reader, completion endpoint and caches. Historical completions cannot change the selected message used by existing actions. Stale thread requests are rejected.
Removed expand/collapse controls. Message headers retain selection for reply, archive and other existing message actions.
HTML remains sandboxed, sanitized and isolated per message. Remote images still require explicit per-message approval. Sender text heights, unsafe line heights and negative margins are removed; safe line boxes and wrapping are enforced.
Frames measure a flow-root content wrapper and coalesce size updates with animation frames. ResizeObserver, image load/error and document font readiness cover content growth and shrink. Already displayed iframe documents are retained when another body arrives. Scroll anchors are preserved.
The display cache retains the selected conversation beyond its ordinary 75-entry count limit while preserving its existing 64 MiB byte limit. This prevents automatic eviction/refetch loops. Messages exceeding the existing byte budget retain the explicit error rather than cycling requests; opening the conversation again retries. Bodies elsewhere in the inbox are not fetched.
