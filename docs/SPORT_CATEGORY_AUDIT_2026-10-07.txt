IMPLEMENTATION AND MODULE COVERAGE
- sports_categories.py: only sport registry; deterministic local options, aliases, validity, saved-state normalization, collection hierarchy hints, conservative inference and prompt-family adapters. No network or database dependency.
- Ads New Ads and Creative Refresh: same complete provider; normalize aliases before keyed widgets; existing winner/prompt logic retained, with generic fallback for sports without bespoke copy rules.
- Posting and CSV: accepts every canonical sport and old aliases. Existing signed saved packages are validated unchanged; only runtime selections/requests normalize. No change to image/copy/card data.
- Meta Review: product category hydration uses shared aliases, sport fields, exact collection hierarchy and tags; unrelated ambiguous sports fail closed for manual selection.
- Google Demand Gen: shared Ads list, backward-compatible CSV category normalization.
- Product command centre/DB forms: shared options and runtime normalization; filters include historical aliases. No migration or stored-record rewrite.
- Social creator/workspace and Reels: shared list, normalized saved state and filename suggestions. Existing athlete keyword hints remain suggestions, not a separate allowed-category list.
- Mockups, Design Ideas/Dashboard/Schedule: shared selectors and normalized subset filters; current custom entry and task data preserved.
- Design Studio/image_factory and Refresh scene adapters: narrow motorsport categories use existing Motorsport treatment; categories without bespoke treatment retain safe general fallback.
- Product Upload collection preview: shared verified sport hierarchy, still advisory and read-only; current catalogue IDs/rules are still required before any assignment.
- Marketing Factory: existing athlete/product hints now return canonical labels; structured sport metadata precedes suggestions.
- SEO: shared list with All Sports / General Sports scope control; legacy editorial custom values retained.
- CRM: shared operator selector; existing seeded segment IDs unchanged; compatible runtime alias comparison. No customer or campaign writes, sends or audience preparation executed.
- Analytics uses record-derived filters rather than an independent sport allowlist. Unrelated keyword/error/task categories and merchandising selectors were intentionally left alone.

ORDER AND SAVED STATE
