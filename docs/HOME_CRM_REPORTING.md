# Home CRM reporting

Home's CRM Morning Brief combines an independently refreshed order ledger with separate paid-platform ROAS and the existing qualitative daily review.

- Sydney calendar dates; Yesterday defaults to the last completed day. Today is explicitly partial and Google ROAS waits until the day closes.
- Shopify cohort: all pages of non-test, non-cancelled orders created in the exact date window. Numeric transaction IDs must match Shopify order IDs exactly; no customer details are requested. Windows older than sixty days require existing read_all_orders access or the entire count is withheld.
- Shopify customerJourneySummary.ready and lastVisit provide the source model. Explicit paid UTMs or Shopify AD/RETARGETING tactics distinguish paid; explicit organic/SEO evidence distinguishes organic. Google product_sync / sag_organic feed tags alone do not establish paid or unpaid traffic and remain Unresolved. Explicit Google click evidence still establishes paid traffic. Bare Facebook/Google referrers and fbclid never establish paid traffic. Missing or contradictory evidence remains Unresolved. First visits are not unioned with last visits. GA4 property 355333982 supplies device from exact purchase transaction-ID matches; tablets/conflicting/missing devices stay Other / unknown. The separately deduplicated GA4 source counts use the same Shopify cohort, and the aggregate source_reconciliation matrix discloses model differences without retaining order identifiers. Organic last visits do not exclude earlier ad interactions. This is an observed last-visit model, not causal proof.
- Facebook includes Instagram: direct account insights, AUD/Sydney, impression-date reporting with unified attribution. Prefer purchase value divided by spend; use the platform's reported purchase ROAS only if value is absent. Purchase aliases are alternatives, never summed. Missing value is unknown, and no spend has no defined ROAS.
- Google covers existing PM021126 campaign in account 6581121605: primary purchase conversion value / spend, ad-interaction date. Longer periods combine summed value and spend across bounded API windows. Budget remains A$20/day; the integration has no campaign mutation calls.
- Platform ROAS can overlap across networks and is not the exclusive order ledger. Organic/SEO has no advertising ROAS.

Native Streamlit period and Refresh controls render aggregate HTML directly, with no custom browser-script dependency. The existing Home fragment updates it automatically. The authenticated Home results endpoint also returns a nonblocking cache snapshot. Refreshes run in bounded background lanes, at most every fifteen minutes, with manual refresh throttled to once a minute. A bounded reconciler in the existing primary app warms yesterday after 05:00 Sydney using that app's existing provider grants; the supporting worker has no CRM provider refresh and cannot overwrite those results with missing connections. No credentials are copied or new services created. Only aggregate counts, ratios, coverage and timestamps are persisted in existing private app_settings keys home_crm_v3:<start>:<end>; raw order/transaction IDs stay transient. Version three withholds feed-only organic claims and adds the visible Shopify/GA4/Ads comparison. Date selection, saved data age, source gaps and partial days are explicit. A late written brief does not stop statistics refreshing.

The existing cloud task 6af6847486588190984cc9941e6f5707 is named CRM — Morning Brief, daily 05:00 Sydney. Its tracking addendum reads get_meta_daily_summary.home_crm and get_growth_analytics.google_ads while preserving its live-sports recommendations and kind meta publication contract.
