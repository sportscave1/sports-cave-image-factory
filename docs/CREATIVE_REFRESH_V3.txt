and prohibits fabricated stock/demand/discounts/delivery/endorsement/signature claims.

product identity and required CTAs can repeat. These are textual heuristics, not semantic certainty.
The collapsed execution-notes area accepts the returned JSON beside the unchanged CSV. Observations,
externally declared reference inspection, role/count/order, concrete scene dimensions, exact source
labels and complete realism/authority blocks are checked before save/package-ready/POST NOW.
Near-identical declared environments and minimal declared winner-room changes are flagged.
Invalid notes JSON blocks readiness while retaining earlier manual notes.
Actual available upload/processed byte hashes catch identical outputs and known unchanged winner or
canonical-source assignments. Canonical-source comparison depends on a supplied source hash;
it cannot certify an unseen stock image. No whole-image similarity/ROAS/novelty percentage is invented.
Final visual inspection is still required for correct product/frame, novelty, glare, clutter and text.

CSV import remains atomic; existing identity/header/row contracts and image order are unchanged.
Saved package hashes include final execution notes before hashing, not after. Legacy package
signatures and setup-note bytes remain unchanged; newer execution data applies only to V3 Refresh.
