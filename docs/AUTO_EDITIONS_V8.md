# Auto Editions V8

Scoped continuation of V7. No compositor, master, source PSD, allocation,
certificate, supplier configuration, Photoshop companion or historical archive changes.

Orders intercepts only cloud download actions for inline generation. The V4
Photoshop fallback retains its existing behavior. Durable server job state is
rehydrated on Orders rendering; the browser initiates a download once per request
and always offers a fallback without claiming successful local saving.
View reuses the existing authenticated Files image viewer with zoom/actual-size
controls and the checksum-verified full-resolution edition endpoint. It does
not regenerate the file. The product/order/edition and actual pixels are shown.

The first file retrieval atomically pins its exact existing Dropbox object for
reprints before streaming it. No duplicate full JPG is created. Retained results
are excluded from automatic cache expiry, with audit records. Historical retained
versions remain accessible only to current authorised Files/Orders users whose
allocation/order-line/unit/product/variant/edition still match. PSD revision
changes do not destroy an already retained reprint. Unretrieved cache files keep
the existing expiry policy. Expired current files can regenerate with bounded
retries from their approved master; changed or ambiguous identities fail closed.
The existing manual archive is untouched and is not bulk imported. Staff must
continue manually saving outputs created outside this verified cloud workflow.

Supplier evidence is keyed by exact SKU: owner-confirmed GLOBAL-CFP-A1 editor
geometry 9933 × 7016 / 841 × 594 mm / 300 PPI is for framed artwork only.
It is not applied to Unframed / XL. No matching unframed specification has been
verified. Bleed, safe margins, colour and quality approval remain incomplete.
The source aspect ratio must match any exact target: no implicit crop/stretch or
unapproved padding. SC3287 remains 8505 × 6012 and TEST / NOT PRINT READY.
The reference template remains 11812 × 8350 / 300 PPI; it is structure-only.
